## Setup

Refer to both react and backend folder README files for instructions on initial setup.

## Run

To run the app, open two seperate terminals.

In the first, run:
```bash
cd backend
uvicorn main:app --reload --port 8000
```

In the second, run:
```bash
cd react
npm run dev
```

Open the local URL shown in the terminal.
